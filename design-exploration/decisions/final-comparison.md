# Final Comparison — Three Directions, One Scenario

Same surfer (Noa, source-cited), same computed recommendation set, same
21-step scenario. Judged on the shared gates.

| Criterion | 01 Shaping Bay | 02 Measure Room | 03 Quiver Deck |
|---|---|---|---|
| Decision value | High — evidence staged as expertise | **Highest — most answers per glance** | High — iteration courage |
| Explainability | Region-anchored notes + chalk ledger | Consequence-sentences on every number | Reasons printed on every swap |
| Comparison quality | Physical side-by-side, few numbers | **Aligned overlay + Δ ruler (best)** | Tug-bars + oversized deltas (fast, coarse) |
| Physical presence | **Best — a lit object in a room** | None (deliberate) | Good — tactile pieces |
| Iteration loop | Present, quiet | Present, formal (stamps/slips) | **Best — the hero mechanic** |
| Accessibility ceiling | DOM mirror required (canvas) | **Native (all DOM/SVG)** | DOM mirror required (canvas) |
| Fallback story | Pre-rendered tiers + chalkboard | **Is the fallback tier** | Flat court tier + tags |
| Technical ownership | Standard R3F | Trivial | Bespoke springs (small, stable) |
| Gimmick risk | Low-moderate (room as dressing) | **Lowest** | Highest (contained by reasons) |
| Weakest moment | Blank form up close | Austere entry | Face-off framing |

## The decision space (no forced winner)

The evidence does not crown a single direction; it clarifies what each would
commit the product to:

- Choose **Shaping Bay** if the product's differentiator is *trust* — the
  experience argues "someone who knows you built this set." Costs: asset
  investment to hit form quality, and a DOM-mirror accessibility program.
- Choose **Measure Room** if the differentiator is *clarity* — it converts
  the product's honesty rules into the interface itself, ships everywhere,
  and is the cheapest to build and maintain. Costs: no object presence; the
  emotional register depends entirely on copy warmth.
- Choose **Quiver Deck** if the differentiator is *iteration* — it makes
  acting on recommendations (keeping, rejecting, re-dealing) feel safe and
  fun, which directly serves the product's decide-don't-browse principle.
  Costs: inspection depth, and discipline to keep play consequence-bearing.

**Composability note (not a fourth direction):** the strongest production
answer may pair one primary experience with Measure-Room-grade comparison as
its comparison mode — D2's overlay engine is deliberately portable, and every
direction already reads from the same scenario store.

If forced to rank on the product's own stated principle (explainability over
everything): **02, then 01, then 03** — but 03 is the only one that makes the
*loop* irresistible, and 01 is the only one a surfer will describe to a
friend. That tension is the real finding of this exploration.
