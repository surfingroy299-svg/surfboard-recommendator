# Extracted Principles

Distilled from `references.md`. These are the load-bearing design rules for the
concept phase — each concept seed is checked against them. "Source" cites the
reference entries that produced the principle.

| ID | Principle | Source |
|---|---|---|
| P1 | **The board's physical form carries credibility.** Surf culture treats the shaped object as the hero; render form first, UI chrome second. | Pocket Quiver, Cord |
| P2 | **Objects primary, controls secondary.** Non-experts succeed when they manipulate the thing itself and controls stay contextual/minimal. | IKEA Kreativ |
| P3 | **Risk-free reversibility invites experimentation.** Destructive-feeling actions (erase, reject) must be visibly safe and undoable. | IKEA Kreativ, Coolors |
| P4 | **Physical response makes objects touchable.** Weight, spring, and momentum turn geometry into a thing you handle — in controlled doses. | Bruno Simon |
| P5 | **Teach by doing.** The first interaction must demonstrate the control model without instructions; feedback is the tutorial. | Bruno Simon |
| P6 | **Lock what you love, regenerate the rest.** Granular commitment converts choice paralysis into iteration. The product's Coolors-loop. | Coolors |
| P7 | **Iteration speed is a feature.** Sub-second response to lock/reject/replace makes exploration feel like play, not paperwork. | Coolors |
| P8 | **Curated camera presets beat free orbit for comprehension.** The product should never be framed badly; free orbit is a bonus within constraints, not the backbone. | Porsche/Polestar, Sketchfab |
| P9 | **Start from a strong default.** Users refine from a curated starting point; they don't build from blank. Mirrors the product's curated 3-board output. | Porsche/Polestar, Cord |
| P10 | **Compare against a personal reference, not spec-vs-spec.** "Better *for me, than what I have*" is the only comparison that matters. | Game inventories |
| P11 | **Show direction and meaning of differences, not raw numbers.** "+easier paddling / −top-end response" beats "31.4L vs 30.8L". | Game inventories |
| P12 | **Dimensions without interpretation are expert-only.** Every number surfaced must carry a consequence sentence. | Cord, Shape3d ecosystem |
| P13 | **Aligned orthographic silhouettes are the shaper-native comparison idiom.** Outline overlay, rocker profile, section stack — information-dense and honest to our L/W/T data. | Shape3d/AkuShaper/BoardCAD |
| P14 | **Authored sequences trade freedom for guaranteed quality.** Pre-rendered/pre-framed presentation is a legitimate high-fidelity alternative — and the natural no-WebGL fallback tier. | Apple scrollytelling |
| P15 | **One universally-known input can drive a spatial experience.** Scroll (or a single drag) needs no teaching; exotic controls do. | Apple scrollytelling |
| P16 | **One state store driving DOM chrome + scene together** is the technical backbone for explanation-annotated 3D at prototype speed. | R3F ecosystem |

## Anti-principles (what the references warn against)

| ID | Warning | Source |
|---|---|---|
| A1 | Navigation-as-obstacle: play that gates information becomes friction when novelty fades. | Bruno Simon |
| A2 | Random replacement destroys trust — our replacement must state *why* the new board differs. | Coolors (inverted) |
| A3 | Option overload / open catalog framing contradicts the product's curated-decision scope. | Configurators, IKEA |
| A4 | Stock 3D staging (gray studio, default environment) reads as "another R3F demo" — art direction must be deliberate per direction. | R3F ecosystem |
| A5 | Stat-sheet density and color-only deltas: our traits are coarse (1–5); deltas must read qualitative, never falsely precise. | Game inventories |
| A6 | Beauty without guidance: photo-real board renders alone leave the intermediate exactly as stuck as a surf shop wall. | Pocket Quiver |
| A7 | Scroll-hijacking and linear narrative can't carry nonlinear inspect/compare/replace loops. | Apple scrollytelling |
