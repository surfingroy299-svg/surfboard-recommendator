# Direction 02 — Visual Model

Independent visual system (no sharing with 01/03).

- **Palette:** deep graphite room `#17191C`; light-table surface warm white
  `#F7F5F0` with a soft glow; ink `#23262B`; drafting blue accent `#2B59C3`
  (guides, chips, stamps); divergence shading amber `#D98324` (the one warm
  note — difference is what matters here); KEEP stamp green-black
  `#1F3D2B`. Contrast pairs verified in build.
- **Typography:** Space Grotesk for headings/title blocks; IBM Plex Mono for
  every number (tabular figures — skill rule); consequence sentences in Space
  Grotesk regular. Type is set like a drawing title block: quiet grid,
  hairline rules.
- **Environment:** one object — the light-table — floating in the graphite
  room; an archive drawer edge at the table's side (replacement source). No
  decor. The table glow is the room's only architecture.
- **Lighting (rendered, not simulated):** the table backlights the plates
  (translucency = stacked-overlay legibility); focused plates cast one soft
  shadow to sell the depth lift.
- **Materials:** plates read as fine translucent drafting film; ink lines are
  crisp vector; the sketch-level rocker curve uses a visibly different dashed
  line weight (honesty encoded in line style, with legend).
- **Controls:** drafting furniture — title blocks, stamps, request slips,
  a view tab that looks like a drawer label. No glass cards, no pill buttons.
- **Motion language:** instrument-precise: 180–260ms ease-out slides, one
  coordinated table flip at 420ms, guides draw in 150ms. Nothing springs,
  nothing floats. Reduced motion: crossfades.
- **DOM ↔ boards relationship:** there is no separation — the boards are
  vector drawings living in the same space as their annotations. This is the
  direction where interface and object fully merge.
